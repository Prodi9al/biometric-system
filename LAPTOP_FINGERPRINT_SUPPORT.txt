================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Windows Hello not detected
SOLUTION:
- Check Windows Hello setup in Settings
- Ensure fingerprint is enrolled in Windows
- Update fingerprint sensor drivers
- Run Windows Hello troubleshooter

ISSUE: Fingerprint capture fails
SOLUTION:
- Clean fingerprint sensor surface
- Ensure finger is dry and clean
- Try different finger placement
- Re-enroll fingerprint in Windows Hello

ISSUE: Poor recognition accuracy
SOLUTION:
- Enroll multiple fingerprints
- Clean sensor regularly
- Ensure consistent finger placement
- Check for sensor driver updates

ISSUE: Sensor not responding
SOLUTION:
- Restart Windows Hello service
- Check Device Manager for errors
- Update Windows and drivers
- Test with Windows Hello settings
