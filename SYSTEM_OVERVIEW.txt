SYSTEM ARCHITECTURE (2024 UPDATE)
==================================

Core Technologies:
- Backend: PHP 8.0+ with MySQL 8.0+ database
- Frontend: Modern HTML5, Tailwind CSS, Vanilla JavaScript
- Biometrics: Python 3.10+ with OpenCV, face_recognition, dlib
- Hardware: WebAuthn API, Windows Hello, Infrared cameras
- Security: HMAC-SHA256, AES-256 encryption, secure sessions
- Service: Flask-based biometric service with real-time processing

Database Structure:
- customers (user accounts, PIN hashes, balances)
- admin_users (staff authentication)
- biometric_data (encrypted face/fingerprint templates)
- transaction_history (audit logs with match scores)
