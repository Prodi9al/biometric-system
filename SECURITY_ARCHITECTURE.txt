SECURITY UPGRADES IMPLEMENTED (2024)
=====================================

1. ENHANCED CHALLENGE-RESPONSE AUTHENTICATION
   - PHP generates cryptographic nonce for each request
   - Python service returns HMAC-signed responses
   - Prevents replay attacks and response tampering
   - 5-minute nonce expiry window
   - AES-256 encryption for sensitive data
   - Rate limiting with progressive delays

2. SECURE SERVICE ARCHITECTURE
   - Flask-based Python service on localhost:5000
   - JSON API with comprehensive input validation
   - No shell execution from PHP (eliminates injection risks)
   - Service isolation and error handling
   - Windows Hello API integration
   - Infrared camera auto-detection
   - Real-time liveness detection algorithms

3. SERVER-SIDE SESSION MANAGEMENT
   - Cryptographic session IDs stored in database
   - Session binding to user ID, timestamp, and auth method
   - Automatic session expiration (1 hour default)
   - Prevents session hijacking and fixation

4. ENHANCED BIOMETRIC DATA LIFECYCLE HYGIENE
   - Raw biometric captures deleted immediately after processing
   - Only encrypted templates stored in database
   - Clear audit trail of data destruction
   - GDPR/privacy compliance built-in
   - Windows Hello secure enclave integration
   - Biometric data never leaves TPM when using hardware
   - Template versioning and migration support

5. COMPREHENSIVE SECURITY LOGGING
   - All authentication attempts logged with metadata
   - NO raw biometric data in logs (security by design)
   - Session tracking and audit trails
   - Rate limiting and attempt monitoring

AUTHENTICATION FLOW
====================

1. PHP generates cryptographic nonce
2. PHP sends nonce + biometric data to Python service
3. Python performs biometric verification
4. Python returns signed response (result + nonce + timestamp + HMAC)
5. PHP verifies HMAC signature and timestamp
6. PHP creates secure session with database binding
7. Raw biometric data deleted from all temporary storage
