================================================================================
BIOMETRIC ATM SYSTEM - REQUIRED DOWNLOADS (2024 UPDATE)
================================================================================

BEFORE EXTRACTING THE SYSTEM, DOWNLOAD AND INSTALL THESE:

1. XAMPP 8.2+ (Web Server + Database)
   Download: https://www.apachefriends.org/download.html
   Size: ~150MB
   Notes: Choose the version for your operating system
          During installation, select Apache and MySQL components
          Run as Administrator for proper permissions

2. Python 3.10+ (REQUIRED for Windows Hello)
   Download: https://www.python.org/downloads/
   Size: ~30MB
   IMPORTANT: During installation, check these boxes:
   ✓ Add Python to PATH
   ✓ Install pip
   ✓ Install for all users (recommended)
   ✓ Add Python to environment variables

3. Visual Studio Build Tools (Windows Only - if dlib fails)
   Download: https://visualstudio.microsoft.com/downloads/#build-tools-for-visual-studio-2022
   Size: ~1GB
   Notes: Only needed if Python face-recognition installation fails
          Select "C++ build tools" during installation

================================================================================
AFTER INSTALLATION, RUN THESE COMMANDS:
================================================================================

Open Command Prompt (Windows) or Terminal (Mac/Linux) and run:

AUTOMATED INSTALLATION (RECOMMENDED):
Double-click: install_requirements.bat

MANUAL INSTALLATION:
pip install opencv-python==4.8.1.78
pip install numpy==1.24.3
pip install face-recognition==1.3.0
pip install dlib==19.24.2
pip install cmake==3.27.7
pip install Pillow==10.0.1
pip install scipy==1.11.3
pip install scikit-image==0.21.0
pip install imutils==0.5.4
pip install pywin32==306
pip install winrt==1.0.21215.1

If any package fails to install, try:
pip install --upgrade pip
pip install package-name --no-cache-dir

For dlib issues on Windows:
pip install dlib-binary

================================================================================
SYSTEM REQUIREMENTS:
================================================================================

Minimum Hardware:
- 8GB RAM (increased for Windows Hello)
- 5GB free disk space
- HD Webcam or Windows Hello camera
- Fingerprint sensor (Windows Hello compatible)
- Internet connection (for initial setup)
- TPM 2.0 chip (for Windows Hello security)

Operating System:
- Windows 10/11 (recommended)
- macOS 10.14+
- Ubuntu 18.04+
- Any Linux distribution with Python 3.8+

Browser Support:
- Chrome 80+ (recommended)
- Firefox 75+
- Edge 80+
- Safari 13+

================================================================================
INSTALLATION STEPS SUMMARY:
================================================================================

1. Install XAMPP → Start Apache & MySQL services
2. Install Python → Verify with: python --version
3. Install Python packages → Run pip install commands above
4. Extract biometric system to: C:\xampp\htdocs\biometric system\
5. Open browser: http://localhost/biometric%20system/create_tables.php
6. Start biometric service: start_biometric_service.bat
7. Test Windows Hello: python/windows_hello.py check

================================================================================
VERIFICATION COMMANDS:
================================================================================

Test if everything is installed correctly:

python --version          (should show Python 3.8+)
pip --version             (should show pip version)
python -c "import cv2"    (should run without errors)
python -c "import face_recognition"  (should run without errors)

TROUBLESHOOTING DOWNLOADS:

Package Installation Issues:
- Use: pip install --user package-name
- Try: python -m pip install package-name
- Update pip: python -m pip install --upgrade pip

================================================================================
OFFLINE INSTALLATION:
================================================================================

If internet is limited on target machine:

1. Download all installers on a machine with internet
2. Download Python packages as wheels:
   pip download opencv-python numpy face-recognition dlib cmake
3. Transfer files to target machine
4. Install offline:
   pip install *.whl --no-index --find-links .
